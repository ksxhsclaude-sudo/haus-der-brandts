# Das Haus der Brandts

Ein Horror-Spiel, das direkt im Browser läuft. Alles steckt in einer einzigen Datei: `index.html`.

- Level 1: Das Haus. Spieluhren sammeln, das Monster blenden, Puppen anschauen.
- Level 2: Das Krankenhaus. Röntgenbilder sammeln, am Blinden vorbeischleichen.
- Mit Freunden: Raum erstellen, Code oder Link teilen, bis zu 6 Spieler zusammen.

Steuerung: WASD laufen, Maus umsehen, Shift rennen, C schleichen, F Taschenlampe, Q Blitz, E Spind, M Karte.
Kopfhörer empfohlen.

Multiplayer läuft Peer-to-Peer über PeerJS (WebRTC). Wer den Raum erstellt, ist Host und berechnet die Monster.
